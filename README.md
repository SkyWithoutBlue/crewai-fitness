# Автоматизация Фитнес-Контента для Instagram с CrewAI 🚀

Этот проект использует команду ИИ-агентов **CrewAI** для автоматизации создания вовлекающих постов и сценариев Reels для продвижения фитнес-платформы **chipizubova.online**.

## Архитектура ИИ-агентов

В проекте задействованы три специализированных агента:
1. **Фитнес-Аналитик трендов и питания:** Исследует научные факты, тренды в спорте и здоровом питании (включая безглютеновое/безлактозное питание), находит цепляющие темы.
2. **Фитнес-Копирайтер:** Пишет структурированные, вовлекающие посты для Instagram с сильным крючком (hook) и призывом к действию (CTA), ведущими на ваш сайт.
3. **Сценарист Reels и креативный директор:** Создает раскадровки, идеи и сценарии для коротких Reels (до 60 сек) для максимального удержания внимания и охватов.

## Быстрый старт

### 1. Подготовка настроек (API Ключи)

1. Скопируйте файл `.env.example` и назовите его `.env`:
   * В Windows (PowerShell):
     ```powershell
     Copy-Item .env.example .env
     ```
2. Откройте созданный файл `.env` в текстовом редакторе.
3. Добавьте ваш API-ключ:
   * **Рекомендуется:** Получите бесплатный или очень дешевый ключ Gemini в [Google AI Studio](https://aistudio.google.com/) и укажите его в строке:
     ```env
     GEMINI_API_KEY=ваш_ключ_здесь
     ```
   * *Или* используйте ключ OpenAI:
     ```env
     OPENAI_API_KEY=ваш_ключ_от_openai
     ```

### 2. Запуск

1. Активируйте виртуальное окружение:
   ```powershell
   .\venv\Scripts\Activate.ps1
   ```
2. Запустите скрипт:
   ```bash
   python main.py
   ```

## Результат

После успешного выполнения агенты создадут файл **`instagram_post_result.md`** в корневой папке проекта. В нем будут находиться:
* Аналитический разбор выбранной темы.
* Готовый к публикации вовлекающий пост (с хэштегами и эмодзи).
* Подробный сценарий Reels с раскадровкой, визуальным рядом, звуками и текстом на экране.
